# Python for Beginners

A collection of Python exercises and projects created while learning Python.

This repository documents my journey of learning Python, starting with basic programming concepts and gradually moving toward more advanced topics and projects.

The goal is to practice what I learn by building small programs and projects and to keep track of my progress over time.

---

## Exercises & Projects

This section contains all of the exercises and projects in this repository, organized in the order they were created.

Each project has its own folder containing the source code and a separate `README.md` with more detailed information about the project.

| # | Project | Description |
|---|---------|-------------|
| 01 | [Rock Paper Scissors](./01-rock-paper-scissors/) | A simple Rock Paper Scissors game built with Python. The player competes against a robot that makes random choices. The first player to reach 3 points wins. |
