# Rock Paper Scissors

**A simple Rock Paper Scissors game written in Python.**

---

## About

This is one of my first Python projects.

The game is played between the **user** and the **robot**.

The first player to reach **3 points** wins the game.

## How to Play

Choose one of these options:

- `R` = Rock
- `P` = Paper
- `S` = Scissors

### Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choice = Draw

## Exit

Type:

`finish`

to exit the game.

## Requirements

- Python 3.x
- No external libraries required

## Run

```bash
python main.py
```
