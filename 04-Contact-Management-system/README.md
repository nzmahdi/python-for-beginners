# Contact Management System

A simple command-line Contact Management System built with Python.

This project allows users to manage their contacts through a menu-driven interface. It was developed as a Python practice project to improve understanding of fundamental programming concepts.

## Features

- Add new contacts
- Edit existing contacts
- Delete contacts
- Search for contacts by name (through dictionary lookup)
- Interactive command-line menu
- Basic input validation

## Concepts & Technologies Used

This project was developed using **Python 3** and the following concepts:

- **Dictionaries:** Store contact names and phone numbers as key-value pairs.
- **Functions:** Organize operations into reusable blocks of code.
- **While Loops:** Keep the application running until the user exits.
- **Conditional Statements:** Control program execution based on user input.
- **User Input & Output:** Interact with users through `input()` and `print()`.
- **Dictionary Methods:** Work with stored data using dictionary operations.
- **F-Strings:** Format output messages dynamically.

## How to Run

1. Make sure Python 3 is installed.
2. Clone or download this repository.
3. Open the project directory.
4. Run the following command:

```bash
python main.py
```

## Current Limitations

- Contacts are stored in memory using a dictionary.
- Data is not saved permanently.
- All contacts will be lost when the application closes.
- The application does not use a database or external libraries.
